Grundläggande element

Meta

html - Huvud element som innehåller hela html filens element

header - Sidhuvud innehåller ev rubrik information om sidan

Layout

head - Element innehåller metadata

style - Används för att definera stilinformation om sidan

footer - Används för att definera sidfoten på en webbsida eller en specifik innehållsavdelning

section - Element representerar ett tematiskt avsnitt i dokument

Text & - Rubriker

p - Paragraf, används för brödtext

h1-h6 - Rubriker i olika nivåer, där h1 är störst och h6 minst

Listor & Navigation

ul - Oordnad lista (punkter)

li - Lista-element i en ul eller ol

nav - Navigationsområde, används för meny eller länkstruktur

Inline-element

span - Inline-element, används för att markera eller styla delar av text

CSS

Typsnitt

font-family - Typsnitt

färger

display

background-color - Bakgrundsfärg

padding - Inre marginal

margin - Yttre marginal

border - Kantlinje

border-radius - Rundade hörn

flex - Flexbox layout

gap - Avstånd mellan flexbox element

justify-content - Justera innehåll horisontellt

align-items - Justera innehåll vertikalt

color - Textfärg

Attribut

class - Används för att definiera en klass för ett HTML-element

id - Används för att definiera ett unikt ID för ett HTML-element

style - Används för att definiera inline-stilar för ett HTML-element
