HTML-element

Meta

<!DOCTYPE>

Denna deklaration specificerar vilken version av HTML som används i dokumentet.

<html>

Rotelementet i ett HTML-dokument som innehåller alla andra element.

<head>

En behållare för metadata om dokumentet, såsom titeln, länkar till stilmallar och metataggar.

<title>

Definierar titeln på HTML-dokumentet, som visas i webbläsarens titelrad eller flik.

<style>

Används för att bädda in CSS (Cascading Style Sheets) i ett HTML-dokument.

<link>

Specificerar externa resurser, som CSS-filer, att användas i dokumentet.

<body>

Huvudinnehållsområdet i HTML-dokumentet där text, bilder och annat innehåll visas.

Semantiska element

<main>

Representerar huvudinnehållet i dokumentet.

<header>

Innehåller vanligtvis introducerande innehåll eller navigation.

<section>

Delar upp innehållet i avsnitt.

<footer>

Innehåller ofta information om företaget eller upphovsrätt.

<article>

Representerar en fristående del av innehåll.

<aside>

Innehåller innehåll som är relaterat till huvudinnehållet.

Text & Rubriker

<a>

Skapar hyperlänkar till andra webbsidor.

<span>

En generisk behållare för text.

<p>

Representerar ett stycke text.

<h1> ... <h6>

Definierar olika nivåer av rubriker.

<ol>

Skapar en ordnad lista.

<ul>

Skapar en oordnad lista.

<li>

Definierar ett listobjekt.

<strong>

Renderar text i fet stil.

<em>

Betonar text genom kursiv stil.

Layout

<div>

En allmän behållare för layout och styling.

CSS-egenskaper

Typsnitt & stilar

font-family

Specificerar typsnitt.

font-weight

Bestämmer tjockleken på text.

font-style

Sätter stil t.ex. italic.

font-size

Anger storleken på text.

text-decoration

Kontrollerar textdekoration.

text-transform

Ändrar text till versaler eller gemener.

Färger

color

Textfärg.

background-color

Bakgrundsfärg.

background-image

Sätter bakgrundsbild eller gradient.

background

Kombinerad bakgrundsegenskap.

Layout

position

Definierar position.

display

Bestämmer hur element visas.

justify-content

Justering i flexbox.

align-items

Justering på tväraxeln.

gap

Avstånd mellan element.

Storlek & marginal

width

Bredd på element.

height

Höjd på element.

margin

Yttre avstånd.

padding

Inre avstånd.

Effekter

object-fit

Styr hur bilder passar i sin box.

aspect-ratio

Anger bredd/höjd-förhållande.

nth-child()

Selektor för element baserat på position.
