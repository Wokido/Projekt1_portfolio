HTML:s Historia

Internet

Internet har sina rötter i militära projekt som ARPANET på 1960-talet. Målet var att skapa ett robust nätverk som kunde fungera även om delar slutade fungera. Detta blev grunden till dagens globala internet.

HTML:s födelse

I början av 1990-talet skapade Tim Berners-Lee World Wide Web (WWW). Han arbetade på CERN och ville göra det lättare för forskare att dela information. HTML var språket som användes för att strukturera innehållet på webbsidor.

World Wide Web

World Wide Web är ett system av sammankopplade webbsidor som nås via internet. Med hjälp av webbläsare kan användare navigera mellan sidor via länkar. WWW är alltså inte samma sak som internet, utan en tjänst ovanpå internet.

W3C

W3C (World Wide Web Consortium) är organisationen som ansvarar för webbstandarder. De ser till att HTML, CSS och andra tekniker fungerar tillsammans oavsett webbläsare. Detta gör webben mer stabil och tillgänglig för alla.

JavaScript & DOM

JavaScript introducerades 1995 och gjorde webbsidor interaktiva. Med DOM (Document Object Model) kan JavaScript ändra innehållet på sidan i realtid, till exempel uppdatera text eller reagera på klick.

2000-talet

Under början av 2000-talet utvecklades webben snabbt. Webbplatser gick från enkla statiska sidor till mer dynamiska upplevelser. Sociala medier och e-handel började bli allt vanligare.

HTML5

Webben har blivit mer avancerad och responsiv. Ramverk som React, Angular och Vue används för att bygga komplexa applikationer. Idag fungerar många webbplatser som appar direkt i webbläsaren.
