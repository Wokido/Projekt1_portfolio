Hjälp & Support

Flexbox eller Grid?

Använd Flexbox för endimensionella layouter som menyer, kort och knappar. Använd CSS Grid för större tvådimensionella layouter.

Varför ser layouten konstig ut?

Kontrollera att alla HTML-element är korrekt stängda och att du inte råkar använda både flex och grid på samma element.

Responsiv design

Sidan är anpassad för mobil, surfplatta och desktop. Använd webbläsarens dev tools för att testa olika skärmstorlekar.

Behöver du mer hjälp?

Läs dokumentationen för Flexbox och CSS Grid på MDN, eller fråga din lärare.
